# Portfólio Profissional de João André Diniz

Este repositório contém o código-fonte do portfólio pessoal de **João André Diniz**, projetado com padrão visual premium, foco em recrutamento técnico, acessibilidade (WCAG 2.1) e SEO otimizado.

## 📁 Estrutura de Pastas

```
joao_andre_portfolio/
├── index.html         # Documento HTML5 semântico e estruturado
├── css/
│   └── styles.css     # Design System em CSS Custom Properties & Responsividade
├── js/
│   └── main.js        # Interatividade (Menu Mobile, Tema, Copiar E-mail, Scroll)
├── img/
│   └── WhatsApp Image 2024-11-13 at 20.46.13.jpeg # Imagem de perfil
└── README.md          # Documentação do projeto
```

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação orientada a acessibilidade e SEO.
- **CSS3 Moderno:** Flexbox, CSS Grid, Variáveis CSS, Glassmorphism e suporte a `prefers-reduced-motion`.
- **JavaScript ES6+:** Sem dependências pesadas, utilizando vanilla JS para interações e manipulação do DOM.
- **Feather Icons:** Biblioteca de ícones vetoriais leve.
